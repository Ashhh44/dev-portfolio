# macOS Web Portfolio
 
A personal portfolio designed as a macOS desktop that runs in the browser. Visitors can open windows, browse files, read my resume and get in touch, all inside a familiar desktop interface.
 
**Live demo:** [ashrafff4.github.io/dev-portfolio](https://ashrafff4.github.io/dev-portfolio/)
 

## Features
 
- **Boot and login screen** with a startup animation
- **Desktop** with draggable icons, widgets (Calendar, Weather, Stocks) and a right-click menu
- **Menu bar and Dock** with icon magnification
- **Window manager**: drag, resize, minimize, maximize and close
- **Built-in apps**: Finder, Launchpad, Safari, Mail, Messages, Maps, Photos, Notes, Calendar, Music, Terminal, Calculator, TextEdit, Preview and Settings
- **Resume** on the desktop, opened in the Preview app
- **Contact Me** window with social links and a message form
- **Dark mode** by default, with a choice of wallpapers in Settings
## Tech Stack
 
- HTML5
- CSS3
- JavaScript (ES6+), no frameworks or build tools
